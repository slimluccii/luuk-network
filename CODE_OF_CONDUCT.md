# Code of conduct

This is my personal website. When you open an issue or comment here, be kind
and respectful, and keep it about the website.

I will remove, lock or hide anything abusive, and block people who keep it up.
If you want to report something without doing it in public, use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature.
