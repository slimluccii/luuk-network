# Security policy

## Supported versions

This repository is the source of [luuk.dk](https://luuk.dk). There
are no released versions. Only the live site and the `main` branch receive
security fixes.

## Reporting a vulnerability

Please open an issue when you find a vulnerability, and include:

- what the problem is and where it occurs, such as a URL or a file
- what an attacker could do with it

Leave out step-by-step instructions for exploiting it, since issues are public.

## What to expect

This is my personal website, and I don't have the time to work on it
continuously. I pick up reports when I can.

## Scope

In scope are the website and the code in this repository, including its
dependencies and its CI workflow. Problems in DatoCMS or in the hosting
provider belong with those services.
