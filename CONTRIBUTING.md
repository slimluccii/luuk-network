# Contributing

This is the source of my personal website. The code is open source under the
[GNU General Public License v3.0](LICENSE), so you are welcome to read it, fork
it and learn from it.

I do not accept pull requests. The website is something I build myself, and I
don't have the time to review outside changes.

What helps is a report when something is broken:

- [Open an issue](https://github.com/slimluccii/luuk.dk/issues/new/choose)
  for a bug, a broken link or a mistake in the content.
- Use the accessibility template when something on the site is hard or
  impossible to use. See the [accessibility statement](ACCESSIBILITY.md).
- Follow the [security policy](SECURITY.md) for a security problem.

Please keep to the [code of conduct](CODE_OF_CONDUCT.md) in issues and
comments.
